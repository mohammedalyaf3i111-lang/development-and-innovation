## Architecture

Next.js App Router, TypeScript, React and Tailwind CSS. `components/landing.tsx` contains reusable section components. `lib/data.ts` owns the product portfolio, divisions and options independently of presentation. CSS illustrations and `app/icon.svg` are original assets; no external image/font requests are required.

## Inquiry configuration

Copy `.env.example` to `.env.local` and provide an approved HTTPS `AISO_INQUIRY_WEBHOOK_URL`. The optional server-only `AISO_INQUIRY_WEBHOOK_TOKEN` is sent as a Bearer token. A successful receiver response (2xx) confirms submission. Requests are validated with Zod, limited to 24KB, checked for same-origin, and protected with a honeypot. Configure infrastructure-level rate limiting before exposing the receiver publicly.

Without a receiver, the form explicitly reports that no inquiry was sent and offers a text download. Nothing is saved to a database. Do not enable public collection until the interim privacy notice and terms have been replaced with company-approved text and a verified privacy contact.

Optional `NEXT_PUBLIC_AISO_WHATSAPP_NUMBER` accepts a verified international number. If blank, no WhatsApp link is shown. Rebuild after changing public configuration or the delivery-enabled state.
